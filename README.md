# Wubs — förhandsvisning

Statisk presentationssida för Wubs AI, etapp 1. Publiceras med GitHub Pages.

Sidan visar hur appen ser ut och vad som är implementerat respektive simulerat.
Den är inte en körande version av produkten — appen körs lokalt och har ännu ingen
riktig inloggning, och ligger därför inte publikt.

Skärmbilderna är tagna från appen med seedad demodata. Siffrorna är påhittade.

Källkoden finns i ett separat, privat repo.
